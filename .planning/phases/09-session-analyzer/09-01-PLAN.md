Create `session-analyzer/cc_session_analyzer.py` (~400-500 lines for this plan, remaining commands added in plans 02-04).

**Structure:**
1. **Imports**: json, argparse, re, sys, datetime, textwrap, pathlib
2. **Constants**: NOISE_PATTERNS list, AGENT_ID_RE regex, USAGE_BLOCK_RE regex, EXIT_CODE_RE regex, DEFAULT_LIMIT = 20
3. **Data layer functions**: `load_session(path)`, `extract_text(content)`, `strip_usage(text)`
4. **Error detection**: `is_noise(text)`, `detect_errors_in_messages(messages)` -- scans tool_result blocks only, returns list of error dicts `{location, context, message, msg_index}`. Each error dict includes: the message index for `msg` command reference, a prompt snippet (first 80 chars of the preceding assistant message or agent prompt), the error text (truncated for overview display). Uses curated patterns per CONTEXT.md D1: is_error flag (primary), Python tracebacks, bash exit codes (^Exit code [1-9] with MULTILINE). Filters NOISE_PATTERNS before counting.
5. **Agent helpers**: `build_agent_map(data)`, `extract_agent_id(text)`, `link_orchestrator_to_agents(data)` -- parses agentId from tool_result messages, builds mapping of tool_use_id -> process_id
6. **Pagination**: `add_pagination_args(subparser)`, `paginate(items, args, command_prefix)` -- default 20, --offset N, --limit N, --all. Footer format: `--- N of M items. Next: <exact command> ---` when more items exist, `--- N of M items ---` when complete.
7. **Persisted output helpers**: `count_persisted(messages)` returns (total, recoverable) by scanning for `<persisted-output>` wrapper and checking file existence. `recover_persisted(text, session_dir)` for content commands (defined here, used in plans 02-03).
8. **Overview command**: `cmd_overview(data, session_file, args)` -- produces plain text output with these sections:
   - **Session**: ID, project path, created date, duration, total tokens, message count, hasSubagents
   - **Size**: file size on disk, chunks dropped notice, processes size estimate, orchestrator size estimate
   - **Timeline**: session start, first error timestamp (if any), session end
   - **Orchestrator**: message count, tool_use count (by tool name top 5)
   - **Agents**: total count, failed count, succeeded count (skip section entirely if no agents)
   - **Errors**: count + list with `msg[N]` reference, prompt snippet, error message (truncated to 120 chars). Show ALL errors in overview (not paginated)
   - **Heaviest Agents**: top 3 by message count with tool breakdown (skip if no agents)
   - **Persisted Outputs**: total count, recoverable count
   - **Commands**: contextual list of available commands. Omit `agent-list`, `agent <prefix>` if no agents. Omit `errors` if no errors. Always show `flow`, `msg`, `search`, `export`. Each command shows brief description and example with session file path.
9. **Argparse setup**:
   - Positional: `session_file`
   - Subcommands: `overview` (no pagination), `errors` (paginated), `flow` (paginated), `agent` (paginated, takes `prefix` arg), `agent-list` (paginated), `msg` (not paginated, takes `index` and optional `agent_prefix` args), `search` (paginated, takes `pattern` arg, `--scope` flag), `export` (not paginated, `--level` flag)
   - Default command when none given: `overview`
   - Stub handler functions for commands not yet implemented (plans 02-04): print "Not yet implemented: <command>" and exit 0
10. **Main block**: Parse args, load session, dispatch to command handler.

**Key implementation details from CONTEXT.md and RESEARCH.md:**
- Content block handling (Pitfall 1): `extract_text()` must handle both `str` and `list[{type: "text", text: "..."}]` formats
- Exit code detection (Pitfall 2): Only scan tool_result blocks. Use `re.search(r"^Exit code [1-9]", text, re.MULTILINE)`
- Agent result status (Pitfall 3): Strip `<usage>` block before checking first/last line for FAILED/ERROR
- Messages without role (Pitfall 4): Skip messages with no `role` field or `type=system`
- Agent linkage (Pitfall 7): Use `processes` array as authoritative agent list. Show `(unknown)` when linkage missing.
- Combined text+tool_use (Pitfall 8): Handle defensively even though no instances observed

**Error detection must NOT import or reference compactor's ERROR_MARKERS** (SAN-22). Implement independently.
