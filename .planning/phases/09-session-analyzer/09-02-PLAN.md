**1. cmd_errors(data, session_file, args):**
- Call `detect_errors_in_messages(data["messages"])` to get error list (from plan 01)
- For each error, build a display entry:
  - Header: `[msg[{index}]] {error_type}` where error_type is "is_error flag" / "Python traceback" / "Bash exit code" / "Agent failure"
  - Context line: `Prompt: {first 80 chars of preceding assistant message or agent prompt}`
  - Error content: Full error text. This is a CONTENT command (SAN-24), so use `recover_persisted(text, session_dir)` to recover persisted outputs. Truncate to first 40 lines with `... ({remaining} more lines)` indicator.
  - Separator: blank line between errors
- Apply pagination to the error list
- Wire into argparse: replace stub handler for `errors` subcommand

**2. cmd_flow(data, session_file, args):**
- Call `link_orchestrator_to_agents(data)` to get tool_use_id -> process mapping
- Iterate over `data["messages"]`, apply mechanical classification rules from CONTEXT.md D2:
  - Skip messages with no `role` or `type == "system"`
  - For `role=user`:
    - Check content blocks for `tool_result` type. If found:
      - Look up the `tool_use_id` to see if it's an Agent return. If so, show: `<timestamp> agent-return {process_id_prefix}: {status}` where status is derived from result text (ok/failed/error)
      - For non-Agent tool_results: skip unless error detected (show error tool results)
    - If content is text/string: `<timestamp> user: {first 80 chars}`
  - For `role=assistant`:
    - Check for `tool_use` blocks in content. If found, emit one line per tool_use:
      - Agent calls (name="Agent"): `<timestamp> -> Agent({prompt_first_60_chars}) [{process_id_prefix}]`
      - Other tools: `<timestamp> -> {tool_name}({input_summary_60_chars})`
    - If text-only content (no tool_use): `<timestamp> asst: {first 80 chars}`
    - If only `thinking` blocks: skip
  - Timestamp format: `HH:MM:SS` from the `timestamp` field. If absent, show `--:--:--`
- Each flow entry is one line. Collect all lines, apply pagination.
- Wire into argparse: replace stub handler for `flow` subcommand

**1. cmd_agent_list(data, session_file, args):**
- Get processes from `data.get("processes", [])`
- For each process, build a one-line summary:
  - `{id[:8]}  {status:6}  {duration:>8}  {msg_count:>4} msgs  {tool_count:>4} tools  {tokens:>8} tok  {prompt_summary}`
  - **ID**: First 8 chars of process `id`
  - **Status**: Derive from process data -- check if `isOngoing` (show "active"), check last message for error patterns, otherwise "ok"
  - **Duration**: Format `durationMs` as `Xm Ys` or `Xs` or `Xms`
  - **Message count**: `len(process.get("messages", []))`
  - **Tool count**: Count `tool_use` blocks across all assistant messages in the process
  - **Tokens**: `process.get("metrics", {}).get("totalTokens", 0)` formatted with commas
  - **Prompt summary**: First 60 chars of the text content from the first `user` message in the process. This is the agent's task prompt.
- Apply pagination
- Wire into argparse: replace stub handler for `agent-list` subcommand
