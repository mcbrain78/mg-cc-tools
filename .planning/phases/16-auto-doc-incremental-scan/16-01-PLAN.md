<feature>
  <name>diff-scan.py: Deterministic Diff Scoping Script</name>
  <files>auto-doc/scripts/diff-scan.py, auto-doc/scripts/tests/test_diff_scan.py</files>
  <behavior>
    Core functionality:
    - resolve_commit(since_timestamp, project_root) resolves ISO timestamp to nearest commit SHA via `git rev-list --max-count=1 --before=<timestamp> HEAD`. Returns None if no commit found.
    - get_changed_files(base_commit, project_root) returns list of file paths changed between base_commit and HEAD via `git diff -M --name-only`. Paths normalized (no leading ./).
    - get_renames(base_commit, project_root) returns dict mapping old_path -> new_path via `git diff -M --diff-filter=R --name-status`. Parses R<score>\t<old>\t<new> format.
    - build_file_to_sections_index(manifests_dir) reads all *.json manifest files and builds reverse index: file_path -> list of {audience, document, section} dicts. Skips _written_sections entries.
    - classify_changes(changed_files, renames, file_index, deleted_check_fn) produces affected_sections (one entry per audience x document x section), new_file_candidates (not in any manifest), and deleted_files (in manifests but deleted from filesystem).
    - discover_gsd_phases(gsd_dir, since_timestamp, project_root) finds *-SUMMARY.md files modified since timestamp via git log, reads them, extracts phase number, name, deviations, key_decisions. Returns empty list if gsd_dir is None or doesn't exist.
    - main() wires all together with argparse CLI: --project-root, --manifests-dir, --docs-dir, --since, --gsd-dir (optional), --output. Writes diff-scope.json via save_json.

    Edge cases:
    - Empty git rev-list result (timestamp before first commit) -> fall back gracefully, no affected sections, summary all zeros
    - No manifests in manifests_dir -> all changed files become new_file_candidates
    - Corrupt manifest JSON -> skip with warning, continue
    - Renamed files produce single affected_sections entries with renames dict, not delete+add
    - --gsd-dir omitted or doesn't exist -> gsd_phases_since: [], all gsd_context: null
    - Paths normalized: strip leading ./ from both git output and manifest file_paths before comparison
  </behavior>
  <implementation>
    Follow the established CLI script pattern: argparse in main(), sys.path.insert for lib imports, subprocess for git commands, save_json for atomic output. Use subprocess.run with capture_output=True, text=True, encoding="utf-8", cwd=project_root for all git calls. ~200-250 lines of production code, ~150-200 lines of tests. Tests use tempfile.TemporaryDirectory with git init + commits to create real git repos for testing. Test imports via importlib.machinery.SourceFileLoader (hyphenated filename pattern). Tests use subprocess to invoke the script as CLI (matching test_add_manifest_entry.py pattern for CLI tests) and direct function imports for unit tests.
  </implementation>
</feature>
