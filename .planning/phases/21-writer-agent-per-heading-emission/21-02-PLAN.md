write-section.py CLI interface (from Phase 19):
```bash
# Top-level section (no --parent):
python3 {SCRIPTS_DIR}/write-section.py \
    --state-file {TMP_DIR}/write-state-devops.json \
    --document {DOCUMENT} \
    --section {section-slug} \
    --content-file {TMP_DIR}/section-devops-{DOCUMENT}-{section-slug}.md \
    --refs-file {TMP_DIR}/refs-devops-{DOCUMENT}-{section-slug}.json \
    --header-file {TMP_DIR}/header-devops-{DOCUMENT}.md \
    --project-root {project_root}

# Child section (--parent is the top-level slug):
python3 {SCRIPTS_DIR}/write-section.py \
    --state-file {TMP_DIR}/write-state-devops.json \
    --document {DOCUMENT} \
    --section {child-slug} \
    --parent {section-slug} \
    --content-file {TMP_DIR}/section-devops-{DOCUMENT}-{child-slug}.md \
    --refs-file {TMP_DIR}/refs-devops-{DOCUMENT}-{child-slug}.json \
    --project-root {project_root}

# Grandchild section (--parent is slash-separated path):
python3 {SCRIPTS_DIR}/write-section.py \
    --state-file {TMP_DIR}/write-state-devops.json \
    --document {DOCUMENT} \
    --section {grandchild-slug} \
    --parent {section-slug}/{child-slug} \
    --content-file {TMP_DIR}/section-devops-{DOCUMENT}-{grandchild-slug}.md \
    --refs-file {TMP_DIR}/refs-devops-{DOCUMENT}-{grandchild-slug}.json \
    --project-root {project_root}
```

Temp file naming convention (include parent slug to prevent collisions):
```
{TMP_DIR}/section-{audience}-{DOCUMENT}-{parent-slug}-{child-slug}.md
{TMP_DIR}/refs-{audience}-{DOCUMENT}-{parent-slug}-{child-slug}.json
```
For top-level sections (no parent), use the existing pattern:
```
{TMP_DIR}/section-{audience}-{DOCUMENT}-{section-slug}.md
```

Section marker injection: write-section.py automatically injects `<!-- section: {slug} -->` before content.
Writers must NOT manually add section markers (Pitfall 6).

    2. **For each ## section** -- a 3-step pattern:

       **Step 1: Emit the intro.** Write ONLY the content between the `##` heading and the first `###` heading (or end of section if no `###` exists). The intro includes: the `##` heading line, the `<!-- docs-meta: ... -->` comment, and any introductory paragraphs. It must NOT include any `###` heading or its content.        **Step 2: Emit each ### child.** For each `###` heading within this `##` section: write the `###` heading line plus its body (up to the next `###` or `####`, not including `####` content) to `{TMP_DIR}/section-devops-{DOCUMENT}-{section-slug}-{child-slug}.md`. Write refs to `{TMP_DIR}/refs-devops-{DOCUMENT}-{section-slug}-{child-slug}.json` with ONLY the typed_refs for entities in this `###` body. Call write-section.py with `--section {child-slug} --parent {section-slug}`.

       **Step 3: Emit each #### grandchild** (if any). For each `####` heading within a `###`: write content to `{TMP_DIR}/section-devops-{DOCUMENT}-{section-slug}-{child-slug}-{grandchild-slug}.md`. Write refs to matching .json. Call write-section.py with `--section {grandchild-slug} --parent {section-slug}/{child-slug}`.

    3. **Ref scoping rule** -- make explicit: "After writing EACH heading's content, IMMEDIATELY write its refs file with ONLY the typed_refs for entities you just referenced in that body. A ref that only appears in a child's content MUST go in the child's refs, not the parent intro's refs."

    4. **Empty intro handling** -- "If a `##` section has no introductory text before the first `###`, the intro content still includes at minimum the `##` heading line and the `<!-- docs-meta: ... -->` comment."

    5. Keep the existing warning about unresolved symbols and the "Do NOT call Write() to create the final document file" note.

    The typed_refs format table, ref type documentation, and all examples should remain unchanged.

    - The unresolved symbols warning
    - The "Do NOT call Write()" directive
