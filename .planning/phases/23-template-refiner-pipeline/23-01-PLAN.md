  <action>
Create `auto-doc/commands/auto-doc-prepare-templates.md` following the auto-doc-generate.md pattern. Structure:

**Frontmatter:**
```yaml
---
name: mg:auto-doc-prepare-templates
description: Produce project-specific refined templates from scan data and shallow source exploration
allowed-tools: Bash, Read, Write, Glob, Grep, Agent
---
```

**Command body (sections):**

1. **Session Context** -- Run emit-context script (same pattern as other auto-doc commands):
   ```
   python3 {EMIT_CONTEXT_SCRIPT} AUTO-DOC
   ```

2. **Before You Start** -- Read schema:
   ```
   Read references/schema.md
   ```

3. **Step 1: Load Config and Scan Data**
   - Read config from `.mg/docs/.docs.config.json` with `{GLOBAL_CONFIG}` fallback
   - Read `docs-scan.json` from `.mg/docs/docs-scan.json`
   - Extract `scan_date` from the scan data top-level field
   - Extract `project_model`, `source_material_index`, and `gap_analysis`
   - Get `project_root` via `pwd`

4. **Step 2: Discover Audience/Document Pairs**
   - Iterate `config.audiences` -- skip audiences where `enabled` is false
   - For each enabled audience, iterate its `documents` array
   - Do NOT process `config.shared_documents` (OVERVIEW, GLOSSARY) -- these are shared documents that don't use audience-specific templates (per Pitfall 7 in RESEARCH.md)
   - Build a list of `(audience, document)` pairs

5. **Step 3: Create Output Directories**
   - For each audience, run: `mkdir -p .mg/docs/templates/{audience}/`

6. **Step 4: Spawn Refiner Agents**
   - For each `(audience, document)` pair, spawn one Agent call:
   ```
   Agent(
     description="Refine template for {audience}/{document}",
     prompt="You are the template refiner agent.

   Read and follow the instructions in: {AGENTS_DIR}/template-refiner.md

   Project root: {project_root}
   Generic template: {TEMPLATES_DIR}/{audience}/{document}.template.md
   Scan data path: {project_root}/.mg/docs/docs-scan.json
   Output path: {project_root}/.mg/docs/templates/{audience}/{document}.template.md
   Audience: {audience}
   Document: {document}
   Scan date: {scan_date}
   Scripts dir: {SCRIPTS_DIR}"
   )
   ```
   - Sequential spawning (one agent at a time) for simplicity per research recommendation

7. **Step 5: Summary**
   - After all agents complete, list the refined templates created:
   ```
   Glob pattern: .mg/docs/templates/**/*.template.md
   ```
   - Print count and paths of refined templates

**Key details:**
- The command uses `{TEMPLATES_DIR}` placeholder for the GENERIC templates (installed to `.claude/auto-doc/references/templates/`)
- Output goes to `.mg/docs/templates/` (project-local, NOT inside `.claude/`)
- Each Agent call passes `{SCRIPTS_DIR}` so the refiner can invoke `get-section-sources.py` and `list-optional-sections.py`

**install.sh update:**
Add `auto-doc-prepare-templates` to the COMMANDS array (after `auto-doc-script`). The agent file (`template-refiner.md`) is automatically deployed by the existing `agents/*.md` wildcard copy in install.sh -- no additional change needed for the agent.
