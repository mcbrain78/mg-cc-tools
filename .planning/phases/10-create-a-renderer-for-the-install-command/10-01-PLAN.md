Add three deterministic rendering subcommands to mg-install-lib.py using TDD: render-status-table, render-tool-picker, and resolve-tool-selection. These replace the LLM's unreliable rendering of the install command's status display and tool selection UI with deterministic Python output.

Purpose: LLMs miscounted summary values, misaligned columns, and varied layout between runs. Moving rendering to Python produces exact, reproducible output every time.
Output: Three working subcommands with full pytest coverage, all consuming scan-status JSON and producing formatted stdout or JSON output.

    2. `render_status_table(scan_data)` — prints formatted table to stdout:
       - Header: `mg-cc-tools v{version} -> {target}`
       - Column headers: Tool, Description, Status
       - Full-width Unicode separator `─`
       - Standard tools (no marker)
       - Dot separator `·` between standard and optional
       - Optional tools with `*` after name
       - Dashed separator `─ ─ ─` before excluded

       - Status legend (6 entries + optional marker note)

       - Status display: "✓ Current", "Update (old -> new)", "Modified (N files)", "Corrupt", "Available", "Excluded"

       - "Select tools to install:" header
       - Standard section header with separator

       - Optional section header with separator
       - Continues numbering from standard section

       - Error: `{"error": "description"}`
       - Deduplicates tool names in result
