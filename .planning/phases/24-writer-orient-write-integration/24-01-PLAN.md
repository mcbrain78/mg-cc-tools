<feature>
  <name>Refined template detection and stale warning in generate-setup.py</name>
  <files>auto-doc/scripts/generate-setup.py, auto-doc/scripts/tests/test_generate_setup.py</files>
  <behavior>
    - Test: detect_refined_templates returns path+stale=false for a non-stale refined template file
    - Test: detect_refined_templates returns null for a missing refined template
    - Test: detect_refined_templates returns stale=true when scan_date is newer than REFINED comment scan date
    - Test: _check_stale returns True when REFINED comment is missing from file
    - Test: _check_stale returns True when file is unreadable
    - Test: _check_stale handles date-only format in REFINED comment and ISO 8601 format in scan_date (normalized to YYYY-MM-DD)
    - Test: detect_refined_templates treats a file with no ## headings as null (absent)
    - Test: stale_templates list in output contains audience/document strings for stale entries
    - Test: full CLI run with --scan-file includes refined_templates and stale_templates keys in JSON output
  </behavior>
  <implementation>
    Add three functions to generate-setup.py:

    1. `detect_refined_templates(project_root, audiences, scan_date)`:
       - Build templates base path: `{project_root}/.mg/docs/templates`
       - For each audience/document pair, check `{base}/{audience}/{DOCUMENT}.template.md`
       - If file exists AND has at least one `## ` heading (via `_has_headings()`): include `{"path": abs_path, "stale": _check_stale(path, scan_date)}`
       - If file missing or has no headings: set to null
       - Return `(refined_templates dict, stale_templates list)`

    2. `_check_stale(template_path, current_scan_date)`:
       - Read first 500 bytes
       - Parse `<!-- REFINED:.*?scan:\s*(\S+)` regex
       - Compare first 10 chars of both dates (YYYY-MM-DD normalization per Pitfall 4)
       - Return True if unreadable, no REFINED comment, or scan is newer
       - Per RESEARCH.md code example

    3. `_has_headings(template_path)`:
       - Read first 2000 bytes and check for `^## ` pattern
       - Return False if no `## ` heading found (Pitfall 5: empty/malformed template)

    In `main()`:
    - After `prepare_workspace()`, read `scan_date` from scan file (load first 2048 bytes like `read_project_root` or read full JSON)
    - Call `detect_refined_templates(project_root, audiences, scan_date)`
    - Add `refined_templates` and `stale_templates` to the result dict

    Tests: Add new test class(es) in test_generate_setup.py. Tests should create temp directories with mock refined templates, mock scan files, and call `_run()` to exercise the full CLI path. Also test the functions directly via importlib if the project pattern allows, or test exclusively via CLI subprocess as per existing test pattern.
  </implementation>
</feature>
