<task type="auto">
  <name>Task 1: Create install.sh with three-mode support and sed resolution</name>
  <files>create-docs/install.sh</files>
  <action>
Create `create-docs/install.sh` following the `codebase-health/install.sh` pattern exactly. Make it executable (`chmod +x`).

**Structure (mirror codebase-health/install.sh):**

1. **Header** -- Bash strict mode (`set -euo pipefail`), script directory detection (`SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"`), usage function.

2. **Argument parsing** -- `while [[ $# -gt 0 ]]; do case "$1" in` pattern supporting:
   - `--project [<dir>]` -- Install to project directory (default: current dir). Optional path argument.
   - `--global` -- Install to `~/.claude/`
   - `--target <path>` -- Install to explicit path
   - `--help` / `-h` -- Print usage

3. **Source validation** -- Before copying, verify these source directories/files exist:
   - `$SCRIPT_DIR/commands/` (directory with .md files)
   - `$SCRIPT_DIR/scripts/` (directory with .py files and lib/)
   - `$SCRIPT_DIR/references/` (directory with schema.md, style-guide.md, .docs.config.json)
   - Print error and exit 1 if any are missing.

4. **Directory creation** -- Create target directories:
   - `$TARGET/.claude/commands/mg/` -- for command .md files
   - `$TARGET/.claude/create-docs/scripts/` -- for Python scripts
   - `$TARGET/.claude/create-docs/scripts/lib/` -- for shared lib
   - `$TARGET/.claude/create-docs/references/` -- for schema, style guide, config
   - `$TARGET/.claude/create-docs/agents/` -- for agent definitions (empty for now, Phase 2 fills)

5. **File copying:**
   - Copy `commands/*.md` to `$TARGET/.claude/commands/mg/`
   - Copy `scripts/*.py` to `$TARGET/.claude/create-docs/scripts/`
   - Copy `scripts/lib/*.py` to `$TARGET/.claude/create-docs/scripts/lib/`
   - Copy `references/schema.md` to `$TARGET/.claude/create-docs/references/`
   - Copy `references/style-guide.md` to `$TARGET/.claude/create-docs/references/`
   - Copy `references/.docs.config.json` to `$TARGET/.claude/create-docs/references/`

6. **Sed path resolution** -- Compute absolute paths and resolve 6 placeholders in copied command files:
   ```bash
   SUPPORT_DIR="$TARGET/.claude/create-docs"
   SCHEMA_ABS="$SUPPORT_DIR/references/schema.md"
   STYLE_GUIDE_ABS="$SUPPORT_DIR/references/style-guide.md"
   CONFIG_ABS="$SUPPORT_DIR/references/.docs.config.json"
   AGENTS_ABS="$SUPPORT_DIR/agents"
   SCRIPTS_ABS="$SUPPORT_DIR/scripts"
   TEMPLATES_ABS="$SUPPORT_DIR/references/templates"
   ```
   For each .md file in `$TARGET/.claude/commands/mg/` that contains a placeholder:
   - `references/schema.md` -> `$SCHEMA_ABS`
   - `references/style-guide.md` -> `$STYLE_GUIDE_ABS`
   - `{GLOBAL_CONFIG}` -> `$CONFIG_ABS`
   - `{SCRIPTS_DIR}` -> `$SCRIPTS_ABS`
   - `{TEMPLATES_DIR}` -> `$TEMPLATES_ABS`
   - `agents/` -> `$AGENTS_ABS/`

   Also resolve in agent .md files under `$SUPPORT_DIR/agents/` (for Phase 2 when they exist).

7. **Project scaffolding** (only for `--project` mode):
   - Create `$TARGET/.mg/docs/` directory
   - Create `$TARGET/.mg/docs/scan-logs/` directory
   - Copy `.docs.config.json` to `$TARGET/.mg/docs/.docs.config.json` (project-local config for customization)
   - Create `$TARGET/.mg/docs/notes-inbox.json` with content: `{"notes": []}`
   - Skip scaffolding if `.mg/docs/` already exists (print message, don't overwrite)

8. **Summary** -- Print what was installed:
   ```
   Installed create-docs to $TARGET/.claude/
     Commands: N command files -> .claude/commands/mg/
     Scripts:  N scripts -> .claude/create-docs/scripts/
     References: schema.md, style-guide.md, .docs.config.json -> .claude/create-docs/references/
     Scaffolded: .mg/docs/ (config, inbox, scan-logs)
   ```

Ensure the script is robust: quote all variable expansions, handle spaces in paths, use `mkdir -p` everywhere, check for existing files before overwriting scaffolding.
