    - Accept `--findings-file` (path to docs-verify-findings.json) and `--output` (where to write results)

    - SEVERITY_ORDER = ["critical", "high", "medium", "low", "info"] (index 0 = most severe)
    - --severity filter: include findings at or above the specified level (use index comparison, per Pitfall 4 in RESEARCH.md)

    - Write result to --output file via save_json
    - If findings file missing, treat as empty array (not error)
